# スライド工房

見たまま操作で、HTML のスライドを作るツール。PowerPoint のようにマウスで部品を置いて、そのまま発表できる 1 個の HTML ファイルとして保存する。

- 保存した HTML は、ブラウザで開くだけで発表できる（ほかのファイルは不要）
- 同じ HTML をこのツールで開けば、続きから編集できる
- ライブラリなし。本体は `index.html` 1 個

## できること

- テキスト・図形（四角、だ円、三角、星、ブロック矢印、吹き出し など）・画像・線と矢印・表
- 移動、拡大縮小、回転、整列、等間隔、グループ化、重なり順、複製、コピー＆貼り付け
- 画像のトリミング、色のパレット、テーマ、スライドサイズ（16:9 / 4:3 / A4）
- スライドマスター（複数作成・スライドごとに適用・タイトルなどの入力欄）
- クリックで順番に出すアニメーション、フェード切り替え、スライド番号、リンク
- 発表者ノート、発表者ビュー（次のスライド・ノート・経過時間）
- 元に戻す／やり直す、自動保存

## 使い方

### アプリ版（専用ウィンドウで動く）

[Node.js](https://nodejs.org/) が必要。

```
npm install
npm start
```

exe つきのフォルダにまとめるとき（Windows）:

```
npm run pack
```

`dist\スライド工房-win32-x64\スライド工房.exe` ができる。

### ブラウザ版

[Python](https://www.python.org/) が必要（追加のインストールは不要）。

`start.bat` をダブルクリックすると、自分の PC の中だけで動く小さなサーバーが起動して、ブラウザでツールが開く。保存した資料は `slides` フォルダに入る。

`index.html` をブラウザで直接開いても使える（保存はブラウザの保存ダイアログになる）。

## 操作の早見表

| やりたいこと | 操作 |
|---|---|
| 選ぶ／まとめて選ぶ | クリック／何もない所からドラッグ |
| 文字を書き換える | ダブルクリック → Esc で確定 |
| まっすぐ動かす | Shift を押しながらドラッグ |
| 保存 | Ctrl+S |
| 元に戻す／やり直す | Ctrl+Z／Ctrl+Y |
| 発表中の操作 | → ← で前後、F で全画面、N でノート、P で発表者ビュー |

くわしくは、ツール右上の「？」から見られる。

## ファイル

- `index.html` … ツール本体
- `app/` … アプリ版（Electron）の起動部分とアイコン
- `tools/serve.py` … ブラウザ版のローカルサーバー
- `tools/pack.js` … アプリ版を exe にまとめる
- `tools/make_icon.py` … アイコンを作り直す
